# Third-party notices

CCA's own source code is licensed under the Apache License 2.0 (see `LICENSE` and `NOTICE`).
CCA's source code and its Python packages (wheel and sdist) **do not contain** the source code,
binaries or weights of the engines and models below; they do contain the web simulator's vendored
browser files (see "Vendored web assets"). The container images `ghcr.io/donquaan/cca` are a
combined distribution: they also bundle Stockfish 19, tini and python-chess, and the `-maia2`
images also Maia-2's code and CPU-only PyTorch; no image contains Maia-2 weights.
This file records how each component is used, so that redistributors know which obligations apply
to them. Licence identifiers were checked against each project's own LICENSE file (2026-09-25,
web assets and image components 2026-09-27). This is an engineering summary, not legal advice.

## Data

Lichess game database exports are released under CC0; they are the intended source for fitting
CCA's hand-set parameters (think-time model, QRE precision, affect dynamics).
